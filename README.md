# Anonymix\_Scoobs\_Real\_Time\_Vocal\_Chords\_Anonymization\_project



Real-time vocal chords anonymiser project - "Software made for tests and analyses and to understand much things in audio processing for my Capstone thesis" : Basically, it was what it meant to be at start, then I wanted to improve it.



Disclaimer : Right now, this project is not made for serious use cases such as bring efficient protection of your vocal chords. Through planned improvements, project's title would be subject to change.

Consider this tool as a fun gadget for this time, that's all.



Planned versions



V1.2: Evaluate a JUCE audio backend and compare it with the current PortAudio implementation.



V1.5: Optimize real-time audio processing in C++ to substantially reduce latency and improve audio quality where possible.



V2.0: Port the application to Rust, using the results measured in the earlier versions.



This roadmap may evolve as the changes are tested. No release dates have been set.
